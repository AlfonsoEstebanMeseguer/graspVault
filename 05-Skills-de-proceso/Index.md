# Index — Skills de proceso

A diferencia de [[03-Invariantes/Index|03-Invariantes]] (reglas de negocio con precedentes de seguridad), estas skills son disciplinas de método reutilizables en cualquier dominio.

| Skill | Cuándo se activa |
|---|---|
| domain-modeling | Terminología del proyecto, GLOSSARY.md, ADRs |
| diagnosing-bugs | "Diagnostica"/"depura", algo roto o lento |
| tdd | Construir features o fixes test-first |
| code-review | Revisar una rama/PR/diff desde un punto fijo |
| research | Investigar contra fuentes primarias en background |
| pr | Escribir el cuerpo de un PR |
| context-curation | Podar `docs/`, `CLAUDE.md`, skills, o código muerto |
| agent-factory | Crear un subagente nuevo |
| find-skills | Buscar skills instalables del ecosistema abierto |
| implement | Construir a partir de una spec o unos tickets ya cerrados |
| wayfinder | Un trabajo que no cabe en una sesión: mapa de tickets de decisión |
| obsidian-markdown | Escribir notas de este vault |
| supabase / supabase-postgres-best-practices | Cualquier tarea de plataforma Supabase |
| `superpowers` (plugin): brainstorming → writing-plans → subagent-driven-development | Cada fase: spec aprobada → plan → ejecución por subagentes con revisión |

Detalle de cada una: [[Como-trabajar-en-este-repo]].
